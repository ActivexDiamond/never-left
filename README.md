# Controls
Move around, find hidden objects and solve puzzles.

Button | Action
:-: | :-
WASD  | Move
E     | Interact
&nbsp;|
F2    | Toggle FPS display.
F3    | Toggle quick-debug display.
F4    | Toggle profiling (full debug).
F11   | Toggle fullscreen (full debug).
ESC   | Quit (immediately closes the game).
